# Notes App

Веб-приложение для ведения деловых заметок в рамках организации. Заметки
группируются по мероприятиям (совещания, собрания, конференции, деловые
встречи), их можно искать по ключевым словам и интервалу даты/времени, а также
сохранять в файл и скачивать на устройство.

## Возможности

- **Организации** — вся работа ведётся в рамках выбранной организации; можно
  создавать, переключать и удалять организации.
- **Мероприятия** — сущность, объединяющая заметки (тип, дата проведения,
  описание).
- **Заметки** — заголовок, дата и время (по умолчанию текущие) и содержание.
  Создаются в рамках мероприятия; мероприятие можно выбрать из списка или создать
  прямо в форме заметки.
- **Главная страница** — заметки, сгруппированные по мероприятиям, по две карточки
  в ряд.
- **Поиск** — по ключевым словам (заголовок и текст) и по интервалу даты/времени.
- **Экспорт** — сохранение отдельной заметки в `.txt` и скачивание на устройство.
- **Хранение** — данные сохраняются в `localStorage` браузера (Pinia +
  persisted state).

## Технологии

- [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) — сборка и dev-сервер
- [Pinia](https://pinia.vuejs.org/) + `pinia-plugin-persistedstate` — состояние
- [Naive UI](https://www.naiveui.com/) — компоненты интерфейса

## Требования

- [Node.js](https://nodejs.org/) версии 18 или выше (рекомендуется 20+)
- npm (поставляется вместе с Node.js)

Проверить версии:

```bash
node -v
npm -v
```

## Установка зависимостей

В корне проекта (папка `notes-app`):

```bash
npm install
```

Команда установит все библиотеки из `package.json` в папку `node_modules`.

## Запуск проекта

### Режим разработки

Запускает локальный dev-сервер с горячей перезагрузкой:

```bash
npm run dev
```

После запуска в терминале появится адрес (обычно `http://localhost:5173`) —
откройте его в браузере.

### Сборка production-версии

Собирает оптимизированную версию приложения в папку `dist`:

```bash
npm run build
```

### Предпросмотр собранной версии

Локально поднимает уже собранный `dist`:

```bash
npm run preview
```

### Проверка типов

Запускает проверку типов TypeScript без сборки:

```bash
npm run type-check
```

## Структура проекта

```
src/
├── assets/            # глобальные стили
├── components/        # Vue-компоненты (организации, мероприятия, заметки)
├── stores/            # Pinia-сторы (organization, notes)
├── types/             # описания типов (Organization, Meeting, Note)
├── utils/             # вспомогательные функции (экспорт заметки в файл)
├── views/             # страницы (HomeView)
├── App.vue            # корневой компонент
└── main.ts            # точка входа
```
